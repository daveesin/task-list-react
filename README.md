# 📝 Task List App

> **Project Status:** Completed

A task management application developed to practice fundamental React concepts, styling with Tailwind CSS, and data persistence in the browser using `localStorage`.

---

## 🎯 Purpose
This project was built as a practical study focusing on:
- React state management (`useState`, `useEffect`)
- Fast and responsive styling with Tailwind CSS
- Client-side data persistence with the Web Storage API (`localStorage`)
- Project setup and build with Vite

## 🛠️ Technologies Used
- **React** (v18+)
- **Vite**
- **Tailwind CSS**
- **JavaScript (ES6+)**

## ✨ Features
- [x] Add new tasks
- [x] Delete existing tasks
- [x] Automatic data persistence via `localStorage`

## 🚀 How to Run Locally

```bash
# Clone this repository
git clone [https://github.com/daveesin/task-list-react.git](https://github.com/daveesin/task-list-react.git)

# Navigate to the project directory
cd task-list-react

# Install dependencies
npm install

# Start the development server
npm run dev
